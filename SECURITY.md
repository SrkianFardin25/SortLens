# Security

SortLens handles people's private photos, so safety and privacy bugs matter most.

## Report a problem privately
Please do **not** open a public issue for a security or data-loss bug. Email shaikhfardin206@gmail.com, or use GitHub's "Report a vulnerability" button on the Security tab. Include the steps to reproduce. You will get a reply as soon as possible.

## What counts
- Any way SortLens deletes, overwrites or changes a user file, or moves one without an approved plan
- Undo that does not restore a file
- The local API being reachable from another computer by default
- Photos, paths or face data leaving the computer

## Supported versions
Only the latest `main` branch is supported while SortLens is in early development.
